# Priyojit Agency Website

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — mobile menu, product filters and WhatsApp enquiry form
- `images/` — supplied product images and logo

## Run in VS Code
1. Extract `priyojit-agency-website.zip`.
2. Open VS Code.
3. Select **File → Open Folder** and choose `priyojit-agency-website`.
4. Install the **Live Server** extension (if not already installed).
5. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but Live Server is recommended.

## Important customisation
- WhatsApp number is in `script.js`: `WHATSAPP_NUMBER = "918609780403"`.
- Phone, email and location text are in `index.html`.
- Sauce currently uses a "Coming Soon" placeholder because no sauce brand/product image was supplied.
- The Darshan artwork is AI-created concept artwork, not verified Darshan retail packaging.
- The enquiry form opens WhatsApp. It does not store submissions in a database.

## Before publishing
- Confirm the contact details and distribution areas.
- Replace the AI Darshan concept image with an actual Darshan product photo when available.
- Add the correct sauce brand and product images.
- Check brand image permissions and use approved product images.
- Test every phone, email and WhatsApp link.
